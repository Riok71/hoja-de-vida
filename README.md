# Hoja de Vida - Johan Stiven Romero Rodriguez

Web desarrollada para la asignatura **Desarrollo de Software I** de la Universidad del Valle (Sede Norte del Cauca).

## Estructura del Proyecto

* `index.html`: Página principal con menú y bienvenida.
* `Pagina1.html`: Perfil personal, datos de contacto, habilidades, proyectos y foto.
* `Pagina2.html`: Información académica y certificado del curso de Precálculo.
* `Estilos.css`: Hoja de estilos compartida para todo el diseño visual.
* `miFTO.jpg`: Foto de perfil.
* `miCRTF.jpg`: Certificado de Precálculo emitido por la Universidad del Valle.

Las páginas `Pagina1.html` y `Pagina2.html` se encuentran enlazadas entre sí mediante botones y barra de navegación.
